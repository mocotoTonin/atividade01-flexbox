Atividade desenvolvida na disciplina de Frameworks Front-end, com o objetivo de praticar os fundamentos do CSS, Box Model e Flexbox.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Google Fonts (Poppins)

## Funcionalidades

- Organização de 20 elementos utilizando Flexbox.
- Aplicação do Box Model (Content, Padding, Border e Margin).
- Layout responsivo para diferentes tamanhos de tela.
- Interface com tema escuro e detalhes em azul.

## Design

- Fundo: `#212121`
- Cor secundária: `#007ACC`
- Fonte: Poppins

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
